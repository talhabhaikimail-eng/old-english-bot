CRITICAL GOTCHAS FOR GITHUB ACTIONS DEPLOYMENT:
1. Entire .env file content is stored in GitHub Repository Secrets as `ENV_FILE`.
2. Both workflows (.github/workflows/run-bridge.yml and browser-worker.yml) write `printf '%s' "$ENV_FILE" > .env`, then `source .env`.
3. Updating GitHub Repository Secrets does NOT update or restart already-running workflows!
   Because run-bridge runs for 5 hours (18000s) and automatically re-dispatches itself, an existing run will continue running with the OLD secrets unless explicitly cancelled.
4. Concurrency has now been configured in run-bridge.yml with cancel-in-progress: true so that new pushes / manual triggers automatically terminate old runs.
5. In .env, ensure CLOUDFLARE_TUNNEL_TOKEN is set to the token for "services main tunnel" (bb28e320...) and BROWSER_TUNNEL_TOKEN is set to the token for "browser-talhacodes" (2808d6e8...). Previously these tokens were mixed up and pointing to the old ufone-claim.site tunnel.
